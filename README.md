# Каталог онлайн-курсов

Небольшая страница каталога онлайн-курсов, сверстанная на HTML и SCSS с использованием JavaScript. Пользователь может фильтровать курсы по категориям и искать их по названию.

## Технологии

- HTML5
- SCSS
- JavaScript (ES-модули)

## Демо

[Открыть проект](https://learning-catalog.netlify.app/)
